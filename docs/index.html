Core Defensive Capabilities

Practical, transparent security mechanics designed without exaggerated marketing claims.

🧠

Markov Sequence Modeling

Models user action sequences (processes, files, logins) as probabilistic state transitions to detect out-of-order anomalies and session hijacking.

🛡️

Windows Firewall Integration

Interacts natively with Windows Defender Firewall (`netsh advfirewall`). Creates tagged inbound/outbound rules (`AIFirewall-*`) for clean uninstallation.

🚫

Safe Hosts File Blocker

Blocks malicious domains locally via loopback redirection. Keeps timestamped rotating backups in AppData and automatically flushes the DNS cache.

💾

Removable Drive Scanner

Monitors USB insertion events, inspects double extensions and suspicious script patterns, detects EICAR signatures, and safely isolates infected files.

🔍

Phishing & Spam Detector

Scans raw messages and suspicious URLs for high-risk lexical patterns, homoglyphs, and obfuscated domains with full offline resilience.

🔐

Local-First & DPAPI Encryption

Zero external telemetry servers. All database records and encryption keys are protected using Windows Data Protection API (DPAPI).

Quick Installation Guide

Get up and running in less than 2 minutes.

1

Download the Installer

Download AI-Firewall-Setup-1.0.0.exe using the link above and launch the executable.

2

Grant Administrator Privileges

Select Yes when prompted by Windows User Account Control (UAC). Administrative rights are required for firewall rule management, process inspection, and hosts file editing.

3

Create Initial Admin Account

On initial startup, complete the first-run wizard by setting an administrative username and password (10+ characters). The setup endpoint locks down immediately afterward.

Windows Defender SmartScreen Notice

What to do if Windows displays an unrecognized publisher warning.

Why does SmartScreen trigger?

Because this is a free open-source release without a multi-thousand-dollar commercial EV signing certificate, Microsoft Defender SmartScreen flags the executable as unrecognized on initial download.

A

Click "More info"

When the blue "Windows protected your PC" screen appears, click the More info link located directly beneath the title.

B

Click "Run anyway"

Click the Run anyway button displayed at the bottom right corner of the dialog.

Known Considerations

Academic & Educational Demonstration

AI Firewall is designed for educational exploration and personal host defense experimentation. It is not an enterprise Next-Generation Firewall or EDR agent. Always maintain up-to-date Windows Defender antivirus protection alongside AI Firewall.
